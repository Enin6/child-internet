# 部署与投稿说明

```

│   ├── hero.webp    # 01 封面：孩子站在发光巨屏前
│   ├── empty.webp   # 02 客厅：孩子蜷在角落借屏幕的光
│   ├── ai.webp      # 03 数字屏：孩子与 AI 光形对话
```

**总大小约 584 KB**，加载极快，不需要任何构建步骤，也不需要 npm。

**页面共 10 屏**（符合通知"不超过 10 屏"限制），需滚动约 11.3 个屏幕高度。

## 二、部署到 Cloudflare Pages

### 方式 A：拖拽上传（最快，1 分钟）

1. 登录 Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Upload assets**
2. 项目名填一个英文名，例如 `child-internet`
3. 把 `h5` 文件夹里的 **`index.html` + `assets` + `_headers`** 一起拖进去
4. Deploy 后得到 `https://child-internet.pages.dev`
5. 在 **Custom domains** 里绑定你的个人域名

> 注意：不要拖 `h5` 这个外层文件夹本身，要拖它**里面**的内容。

### 方式 B：命令行

```bash
npx wrangler pages deploy ./h5 --project-name=child-internet
```

### 方式 C：Git 直连

推送到 GitHub 后，在 Pages 里连仓库：
- Build command：**留空**
- Build output directory：**`/`**（或 `h5`，看你放哪一层）

## 三、绑定个人域名

Pages 项目 → **Custom domains** → **Set up a custom domain**

- 若域名就在 Cloudflare 托管：填进去会自动加 CNAME，几秒钟生效
- 若在别家：去域名商加一条 CNAME 指向 `xxx.pages.dev`

**建议同时保留 `pages.dev` 的地址**，万一自定义域名出问题还有备份。

## 六、想改内容怎么改

全部在一个文件里，搜索这些关键词定位：

| 想改什么 | 搜什么 |
|---|---|
| 某屏正文 | `========== 0X` 这样的注释 |
| 字号大小 | `clamp(` |
| 主色（橙红） | `--accent` |
| 金色高亮 | `--gold` |
| 每屏滚动长度 | `--beats` |
| 数字屏的数字 | `data-count` |
| 结尾署名 | `end-sign` |

**滚动节奏**：`--beats` 是这一屏要滚动几屏高度。想让某屏停留久一点，把数字调大（比如 `--beats:2` → `2.5`）。

> 本作品保留了原始文件作为凭证，如主办方询问可提供来源链接。

### 处理方式

治愈系钢琴独奏，音符稀疏、节奏舒缓、情绪温暖而不煽情——适合本作品的理性评论基调。

- 截取前 **72 秒**，可无缝循环
- 首 **1.8 秒**淡入、尾 **4.5 秒**淡出
- 峰值对齐到 0.86（后调至 0.859，防削波），RMS -16.5 dB
- 软限幅处理，保留钢琴瞬态而不失真
- 重编码为 **48 kbps 单声道 / 32 kHz**，体积 422 KB

**筛选依据**（12 首候选中选出）：
起音密度 0.5 次/秒（最低组，说明是清亮的独奏而非密集伴奏）、
动态范围 23 dB（最小，最平稳）、明亮度 0.007（温和不刺耳）。

### 播放逻辑（合规要点）

**默认打开播放**，用户可随时手动关闭：

- 页面加载即尝试自动播放，音量在 2.4 秒内淡入到 40%
- **若浏览器拦截自动播放**（首次访问常见），会自动降级：
  用户**第一次点击/滑动/按键**页面时立即开始播放，无需再点按钮
- 右上角按钮显示当前状态（"播放中" 金色 / "音乐" 橙红）
- 点击按钮可随时暂停，0.4 秒淡出
- 切到后台（切标签页/锁屏）自动暂停，切回自动恢复（若用户未手动关闭）
- 按钮有 `aria-label` 与 `aria-pressed`，支持键盘操作

> 说明：浏览器出于体验考虑，禁止网页在用户无交互时突然出声。
> 本作品做了"能自动就自动，被拦截则首次交互即播放"的双重处理，
> 在合规前提下最大化"默认有声"的体验。

### 如果想换音乐

1. 把新的 mp3 放到 `assets/bgm.mp3`（覆盖）
2. **务必确认授权允许商用**，并把来源记在这里
3. 建议控制在 500 KB 以内、60-120 秒、无强烈旋律
4. 不需要改任何代码

### 如果不想用音乐

删掉 `index.html` 里的这两行即可：

```html
<button class="bgm-toggle" id="bgmToggle" ...>...</button>
<audio id="bgm" src="assets/bgm.mp3" loop preload="none"></audio>
```

再删掉 `<script>` 里"6. 背景音乐"那一段。作品其余部分不受影响。
